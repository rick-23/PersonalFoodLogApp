# PersonalFoodLogApp

A food logging app to track meals and get insights into your eating habits.

## Tech Stack

- **Frontend:** React Native (Expo), React Navigation
- **Backend:** Node.js, Express, PostgreSQL
- **Auth:** JWT, bcrypt

## Getting Started

### Backend
```sh
cd PersonalFoodLogApp/backend
npm install
npm run dev
```

### Frontend
```sh
cd PersonalFoodLogApp/frontend
npm install
npm start
```

This project is being actively refurbished to the latest dependency versions.
